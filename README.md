# Forgejo — Terraform + Ansible Configuration

Deploys a self-hosted [Forgejo](https://forgejo.org) Git service using a two-stage pipeline:

- **Terraform** provisions the host (Proxmox LXC container) and generates the Ansible inventory
- **Ansible** deploys the Forgejo Docker container with HTTPS and SSH

## What This Deploys

One Docker-enabled container running:

- **Forgejo** — Self-hosted Git service
  - 2 CPU cores, 2 GB RAM, 1 GB swap, 50 GB storage
  - HTTPS on port 3000 with a self-signed certificate
  - Git SSH on port 2222
  - SQLite database

## Environments

| Aspect         | proxmox-prod                          | vagrant-vb                          |
| -------------- | ------------------------------------- | ----------------------------------- |
| Infrastructure | Proxmox LXC container                 | Vagrant VirtualBox VM               |
| Purpose        | Production workload                   | Local Ansible development & testing |
| Networking     | Static IP                             | Port forwarding (localhost)         |
| SSH User       | root                                  | vagrant                             |
| SSH Auth       | SSH agent key                         | Vagrant-generated key               |
| Base Image     | `debian13-docker_v29-template.tar.gz` | `cloud-image/debian-13`             |

## Prerequisites

- Terraform >= 1.0
- Ansible >= 2.9 with `community.docker` collection (`ansible-galaxy collection install community.docker`)
- For **proxmox-prod**: Proxmox VE server with API access and a Debian 13 Docker LXC template
- For **vagrant-vb**: VirtualBox and Vagrant with `vagrant-disksize` plugin

## TLS Certificate

Forgejo runs with a self-signed certificate. The cert must be stored in (`ansible/files/forgejo/forgejo.crt`) alongside with the key (`ansible/files/forgejo/forgejo.key`). Both files are git-ignored and must be present locally before running Ansible.

To generate a self-signed cert for your domain:

```bash
openssl req -x509 -newkey rsa:2048 -nodes \
  -keyout ansible/files/forgejo/forgejo.key \
  -out ansible/files/forgejo/forgejo.crt \
  -days 3650 \
  -subj "/CN=forgejo.example.com" \
  -addext "subjectAltName=DNS:forgejo.example.com"
```

See [homelab-self-signed-cert-setup](https://github.com/renewelches/homelab-self-signed-cert-setup) if you want to create your own ROOT CA for self signing.

## Setup

### 1. Configure Terraform Variables

```bash
cd terraform/environments/prod/proxmox
cp terraform.tfvars.example terraform.tfvars
# Edit with your Proxmox details and forgejo_domain
```

Sensitive values via environment variables:

```bash
export TF_VAR_proxmox_api_token="terraform@pve!provider=..."
export TF_VAR_proxmox_host_default_pwd="your-password"
```

### 2. Deploy

**Proxmox (prod)**

```bash
cd terraform/environments/prod/proxmox
terraform init && terraform apply
# Generates: ansible/inventory/prod/proxmox/inventory.ini

# From repo root
ANSIBLE_CONFIG=ansible/inventory/prod/proxmox/ansible.cfg \
  ansible-playbook -i ansible/inventory/prod/proxmox/inventory.ini \
  ansible/deploy-forgejo-stack.yml
```

**VirtualBox dev**

```bash
cd vagrant/vagrant-vb
vagrant up
./gen-inventory.sh forgejo.example.com

# From repo root
ANSIBLE_CONFIG=ansible/inventory/dev/vagrant-vb/ansible.cfg \
  ansible-playbook -i ansible/inventory/dev/vagrant-vb/inventory.ini \
  ansible/deploy-forgejo-stack.yml
```

### 3. SSH Agent (proxmox-prod only)

```bash
eval $(ssh-agent)
ssh-add ~/.ssh/id_rsa
```

## First Run

On first access Forgejo shows an installation wizard at `https://<forgejo_domain>` (or `https://<static_ip>:3000`). Complete it to create your admin account.
